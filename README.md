# dsh-better

> **Unofficial community plugin.** Not affiliated with DeepSeek. 非官方社区插件，与 DeepSeek 官方无关。依靠AI生产的代码。

更好的 DSH —— 一个符合 DeepSeek Harness 插件标准的双半部插件（host + browser），为 dsh Web GUI 补上几件顺手的小工具：归档会话管理、系统级任务通知、版本检查、模型路由与仿 DeepSeek 官网的消息滚动导航。所有能力都在「设置 → 更好的 DSH」下，随装随用。

中文 · [English](README.en.md)

## 安装

已发布到 npm，终端里一条命令即可装入你的 DSH：

```bash
dsh plugin --profile web add dsh-better
```

安装后重启 DSH 生效，设置页出现「更好的 DSH」入口。

## 功能

### 已归档会话

dsh 归档的对话不会消失，只是官方界面再也看不到它们——这里把每一条都列出来：

- 一览各归档的标题线索、工作目录、归档时间与本地日志状态；
- **复原**：送回原来工作区的原位置，接着聊；
- **彻底删除**：连同本地日志一起清干净，不留幽灵记录。

复原/删除通过开放的工作区持久层直接落盘，并复用网关自身的变更事件流——所有打开着的页面实时收敛，无需手动刷新。

### 任务通知

网页保持打开时，任务一旦停止就弹出**系统原生通知**（Windows Toast / macOS / Linux 桌面通知），三种时机各自可开关：

- Agent 提问或给出选项（等你回复）；
- 任务完成（正常收尾）；
- 任务出错（异常停止）。

实现上以**可逆方式**包装会话生命周期回调来感知状态变化：插件停用时逐个还原被包装的原型方法并清空内部状态，不留任何残留观察者。

### 检查更新

对比本机 dsh 与 GitHub Releases 上的最新发布（完整 semver 规则，含预发布比较）：

- 自动识别安装形态与源码目录：从运行入口向上找最近的 `@deepseek-ai/dsh` 包 → pnpm 全局 store → 约定目录扫描，也可用环境变量 `DSH_BETTER_REPO_ROOT` 手动指定；
- 内置两套一键复制的更新命令：「npm 包安装」（如 `npm install -g @deepseek-ai/dsh@latest`）与「源码构建」；
- 最新版本走三级来源获取（Releases API → 发布列表 → 跨主机 atom 源），配 5 分钟缓存、24 小时陈旧回退与失败快路径——GitHub 抽风时面板照常能用；
- 可一键在源码目录弹出独立终端窗口，命令由你自己粘贴执行。

### 模型路由

按关键词规则把会话切换到指定模型（设计移植自 [dsh-model-router](https://github.com/superboy911/dsh-model-router)，按需裁剪）：

- 规则按顺序匹配用户消息，首个命中即生效，未命中不做任何改动；
- 目标是提供方 / 模型 / 推理强度三元组，写入前对运行时注册表**精确校验**，不存在或已下线的组合直接拒绝；
- 可选开启 `model_route` 工具，让智能体在对话中自主切换模型——且只能切到白名单里逐条列出的组合。

所有配置改动实时生效，无需重启。

### 侧边滚动栏

1:1 复刻 [chat.deepseek.com](https://chat.deepseek.com) 的滚动导航，挂在会话区右缘：

- 你发出的每条消息（含运行中插话）对应一根刻度线，均匀分布在毛玻璃胶囊轨道上；
- 鼠标悬浮弹出**预览小窗**：一条消息对一根刻度，消息多时窗内可滚轮翻阅，上下带渐隐提示；
- 点击任意一行直达那条消息；当前正在浏览的消息刻度会放大并高亮为品牌色；
- 默认自动适配浅色/深色主题（白/黑半透明胶囊、主题化小窗与文字色）；
- 设置页可开关自定义配色：轨道、小窗背景、刻度、悬浮行、激活品牌色、预览文字，改动即时生效。

## 实现方式

标准双半部插件：

- **宿主半部**运行在 Node 后端进程内，注册一组仅回环可达的 exact API 路由；**浏览器半部**按页加载，向设置页注入界面与交互；
- 三层安全栅栏：只接受回环连接、校验 `Host` 头（防 DNS 重绑定）、POST 强制声明 `application/json`（跨站"简单请求"无法伪造该头，而这些路由也永不应答 CORS 预检）；
- 对 dsh 运行时的依赖全部在运行期解析：缺哪一块就单独降级对应功能并给出警告，绝不拖垮后端启动。

界面上我们有点小骄傲：**全程沿用 dsh 原版的设计语言**——颜色、圆角、间距、字体一律取自当前主题的语义变量，不引入任何第三方样式。无论你换到哪个主题，它都像原生自带的功能页一样自然融入。
