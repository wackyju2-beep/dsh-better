# dsh-better

> **Unofficial community plugin.** Not affiliated with DeepSeek. 非官方社区插件，与 DeepSeek 官方无关。依靠AI生产的代码。

更好的 DSH —— 一个符合 DeepSeek Harness 插件标准的双半部插件（host + browser），为 dsh Web GUI 补上几件顺手的小工具：归档会话管理、系统级任务通知、版本检查、模型路由与仿 DeepSeek 官网的消息滚动导航。所有能力都在「设置 → 更好的 DSH」下，随装随用。

中文 · [English](README.en.md)

## 安装

已发布到 npm，终端里一条命令即可装入你的 DSH：

```bash
dsh plugin --profile web add dsh-better
```

安装后重启 DSH 生效，设置页出现「更好的 DSH」入口。

## 功能

设置 → 更好的 DSH：

- **已归档会话** —— 列出所有已归档对话（标题线索、工作目录、归档时间、本地日志状态），可复原回原工作区原位置接着聊，也可连同本地日志彻底删除；
- **任务通知** —— 网页保持打开时，任务停止即弹出系统原生通知（Windows Toast / macOS / Linux 桌面通知）：Agent 提问或给出选项、任务完成、任务出错三种时机各自可开关；
- **检查更新** —— 对比本机 dsh 与 GitHub Releases 最新发布（完整 semver 规则），一键复制全套更新命令，也可在源码目录弹出独立终端窗口供你粘贴执行；
- **模型路由** —— 关键词规则按顺序匹配用户消息，首个命中即把会话切到指定提供方 / 模型 / 推理强度；可选开启 `model_route` 工具让智能体在对话中自主切换（设计移植自 [dsh-model-router](https://github.com/superboy911/dsh-model-router)，按需裁剪）；
- **侧边滚动栏** —— 1:1 复刻 [chat.deepseek.com](https://chat.deepseek.com) 的滚动导航：每条你发出的消息对应一根刻度线，悬浮预览、点击直达，配色可在设置页自定义。**默认关闭**；开启后会替代官方内置的轮次导航，关闭即原样还原。

所有配置改动实时生效，无需重启。

## 实现方式

标准双半部插件：**宿主半部**运行在 Node 后端进程内，注册一组仅回环可达的 `/api/dsh-better/*` exact API 路由；**浏览器半部**按页加载，向设置页注入界面与交互，经由上述路由与宿主通信。

对 dsh 运行时的依赖全部在运行期解析：dsh-better 经符号链接目录加载，无法静态 `import "@deepseek-ai/*"`，宿主半部以启动入口为锚点解析所需宿主模块（与运行实例同一份构建产物），缺哪一块就单独降级对应功能并给出警告，绝不拖垮后端启动。

三层安全栅栏：只接受回环连接；校验 `Host` 头（防 DNS 重绑定）；POST 强制声明 `application/json`——跨站"简单请求"无法伪造该头，而这些路由也永不应答 CORS 预检，跨站伪造页面动不了你的存档。

### 已归档会话

- 复原/删除通过开放的工作区持久层直接落盘。归档从不改动工作区记账，所以复原即还原：把会话从全局归档集移除，回到原工作区的原位置；
- 删除会清掉本地 `.jsonl` 会话日志，并从工作区记录与归档集中一并移除；正在直播的会话拒绝删除（`session-live`）；
- 所有变更直接写持久化的 workspace 域，浏览器经由网关现有的 `domain/changed` 转发即时收敛——所有打开着的页面无需手动刷新。

### 任务通知

- 由标准浏览器 Notification API 实现，跨平台通用（Windows Toast / macOS 通知中心 / Linux freedesktop 桌面通知，带 DeepSeek 鲸鱼图标）；关闭网页后通知自然停止，这是该 API 的固有边界；
- 通知引擎以**可逆方式**包装会话运行时的两个帧入口来观察事件流：只旁路观察、绝不改动分发；插件停用时逐个还原被包装的原型方法并清空内部状态（包装器自带标记，防止重复启用后叠层），不留任何残留观察者；
- 提问挂起期间死掉的会话不再永久吞掉完成通知（挂起登记随新运行自动清理）；子代理子会话默认不重复提醒；
- 授权状态、启用开关与三类时机开关保存在浏览器本地（localStorage）。

### 检查更新

- **目录发现链**（结果在进程内缓存）：`DSH_BETTER_REPO_ROOT` 环境变量显式指定 → 从启动入口（`argv[1]`）与工作目录向上查找最近的 `@deepseek-ai/dsh` package.json（源码运行与打包安装都能命中）→ node 可执行文件旁的 pnpm 全局 store → 约定路径扫描 `<盘符>:\.dsh\deepseek-harness`。路径含 node_modules 判为「发行包安装」，apps/cli 布局判为「源码构建」；盘扫与 pnpm 探测是 Windows 特有，unix 上静默跳过；
- **取版本三级源**，任一可用即成功：`/releases/latest`（该端点排除预发布——上游 release 全是预发布时恒 404，属预期）→ `/releases` 列表取首个非草稿（失败重试 1 次）→ `github.com/<repo>/releases.atom` 订阅源（与前两者不同主机，api.github.com 整体故障时的独立通路，重试 1 次）。单请求超时 9 秒；成功缓存 5 分钟；24 小时内有过成功值时，全源失败兜底展示旧值并带「缓存数据（可能过期）」徽章——陈旧数据优于白屏报错；
- 检查更新移出共享串行队列，带并发去重与失败缓存：GitHub 抽风时面板照常能用，也不阻塞其余功能；
- 版本比较遵循完整 semver 规则（`0.1.1-rc.2 < 0.1.1`、数字预发布标识符按数值比较），比较器单独导出供测试；
- **弹终端**：Windows 经 `cmd /d /s /c start` 为内层 cmd 分配全新控制台——绕开 `detached: true` 等价 `DETACHED_PROCESS`、控制台程序不分配任何控制台的坑；macOS `open -a Terminal`；Linux 依次尝试 x-terminal-emulator / gnome-terminal / konsole / xfce4-terminal，以 250ms error-race 区分「缺程序」与真实启动，迟发 error 挂 no-op 监听防止拖崩后端。窗口完全独立于后端生命周期，不受其管理或终止，命令由你自己粘贴执行，插件绝不代输。

### 模型路由

- 引擎的规则匹配、目标校验等纯函数部分与原版 [dsh-model-router](https://github.com/superboy911/dsh-model-router) 逐行同源；配置持久化在独立 settings 命名空间 `better-model-router`（刻意区别于原版插件，二者可以共存）；
- 规则按顺序匹配用户消息文本，**命中即停；未命中不改动会话**。写入会话前先对 DSH 实时注册表精确校验（提供方须已激活、模型须可解析、推理强度须被支持），校验失败不写会话；休眠目标可保存但不会执行；
- 子代理会话默认不应用会话头选择，引擎会惰性安装官方选择装配，让关键词规则在子代理第一条请求即生效；
- 可选 `model_route` 工具（默认关闭）：开启后智能体可在对话中自主切换当前会话模型，但只能切到白名单里逐条精确列出的组合，每次执行仍经实时精确校验；开启但白名单为空时不注册任何工具；聊天流中有对应的路由卡片；
- 只读路由移出共享串行队列、规则目标并行校验、上游请求带超时上限，打开路由页不会拖慢其余功能；保存走版本号乐观锁，配置被其他窗口改动时明确提示冲突。

### 侧边滚动栏

> **官方已有内置替代（v0.4.1 起本功能默认关闭）**：dsh 0.1.2-alpha.1 起官方自带了「轮次导航」（会话右侧的回合刻度条）。本功能转为可选增强——默认关闭，保持官方原样；开启后，只要刻度导航实际显示（会话超一屏且用户消息已载入）就暂时隐藏官方轮次导航、由本功能接管；关闭开关或刻度尚未显示期间，官方导航自动原样回归，不存在"两个都不见"的死区。跳转逻辑已改为与官方轮次导航同一套语义（瞬时定位写入，配合官方的滚动台账），此前"运行中会话点击跳转被流式输出拽回底部"的老问题随官方重写一并根治。开关实时生效，无需刷新页面。

- 从 chat.deepseek.com 的生产样式表逆向其滚动导航的类名与布局，1:1 复刻为毛玻璃胶囊轨道；
- 刻度直接从会话快照派生：`user` / `steering`（运行中插话）聊天节点各对应一根刻度，以稳定锚点 key 对齐到渲染出的消息行；
- 一条长生命周期的监听器维护全部 DOM 派生状态：滚动监听以捕获阶段委托一次性绑定（任何元素的滚动都能到达这里，会话中途换上新滚动容器也会在第一次滚动时自动重定向），`ResizeObserver` 跟随布局变化；当前浏览位置的判定在每次滚动时同步计算——刻意不用 rAF，后台标签页里 rAF 冻结会让高亮刻度滞留旧位置；
- 点击刻度把会话滚动容器瞬时滚到对应消息行——与官方轮次导航同一套机制（单次 scrollTop 写入，官方滚动台账将其识别为程序写入而非读者输入，从而自行解除底部跟随）；旧版的 5 秒心跳重申守卫随官方滚动系统重写一并退役；
- 对官方轮次导航的隐藏不依赖任何构建期类名（官方类名是 CSS Modules 哈希），只认官方滚动容器内的 `nav` 元素；插件自己的导航带专属标记，绝不会被误伤；
- 主题色用 CSS `light-dark()` 自动跟随浅色/深色；自定义配色保存在浏览器本地（localStorage），改动即时生效。

界面上我们有点小骄傲：**全程沿用 dsh 原版的设计语言**——颜色、圆角、间距、字体一律取自当前主题的语义变量，不引入任何第三方样式。无论你换到哪个主题，它都像原生自带的功能页一样自然融入。
